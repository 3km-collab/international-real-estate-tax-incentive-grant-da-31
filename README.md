# International Real Estate Tax Incentive & Grant Database

**Ready-to-use verified reference pack by InternationalLabs — compiled compiled 2026-11.**

## What's inside (exact contents)

- **Lender Directory**: 27 real capital sources — Fannie Mae DUS, Freddie Mac Optigo, HUD/FHA 221(d)(4) & 223(f), Greystone, Walker & Dunlop, Berkadia, CBRE/JLL/Eastdil capital markets, PGIM, MetLife, New York Life, Wells Fargo, JPMorgan, Bank of America, PNC, KeyBank, SMBC, Aareal, ABN AMRO, Santander, OakNorth, Ready Capital, CoreVest, Bridge, Fortress, Trez — with loan-size ranges, **max LTV**, property types and signature program terms.
- **Program Compare**: pick a lender → INDEX/MATCH profile pull.
- **Financing Planner**: max loan by LTV vs DSCR (formula-driven, binding constraint).
- **Sources & Verification** + User Guide.
- Formats: Excel (5 sheets) + CSV + JSON + offline HTML dashboard. Free Lite sample.

## How much research time this saves you

Building this file by hand means reading official fee pages, tariff sheets and
lender program guides from dozens of sources, normalising them into one
comparable structure, and re-checking every link. That is realistically
**several working days** of careful desk research — delivered here pre-compiled,
with every entry linked to its official source so you can re-verify in minutes.

## Who this is designed for

Investors and sponsors financing multifamily/commercial deals: GP teams, family offices, brokers.

## How to use it

1) Shortlist lenders by type/LTV in the directory. 2) Compare two programs side-by-side. 3) Size your loan in the planner. 4) Confirm terms with the lender's official page.

## Try before you buy

The `lite/` folder contains a real subset you can open right now — no demo
skeletons, actual rows/sheets from the full file.

## Verification policy

Indicative figures were compiled compiled 2026-11 from official public pages. Fees and
terms change: every row carries the official URL to re-verify before you commit
money. This file is a planning reference, not a binding quote.
